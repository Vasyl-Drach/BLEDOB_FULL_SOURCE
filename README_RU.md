# BLEDOB Lights 2.0 · управление RGB-лентой (Android)

Бесплатное офлайн-приложение для BLE-контроллера **BLEDOB** (Lotus Lantern / совместимые ELK-BLEDOB).

## Возможности

- Цветовой HSV-круг: оттенок и насыщенность; изменения передаются через Bluetooth.
- 8 быстрых цветов, включая белый.
- Ползунок яркости 1–100 %.
- Вкл/выкл прямо с экрана приложения.
- Сохранение выбранного цвета и яркости на телефоне.
- Одноклеточный ярлык «Свет» без открытия экрана приложения.
- Сохранён старый виджет для переключения света (размер зависит от оболочки Android).
- BLE-подключение без интернета, рекламы, аккаунта и внешних библиотек.

**Важно:** именно питание уже работало на пользовательском BLEDOB в версии 1.4. Команды RGB и яркости соответствуют открыто задокументированному протоколу Lotus Lantern, но **ещё не проверены на конкретном контроллере пользователя**. При необходимости переключи вариант протокола внизу экрана.

## Как установить и проверить

1. Загрузить распакованное содержимое ZIP с названием `UPLOAD_GITHUB` в существующий репозиторий GitHub, разрешив замену старых файлов. Файл `.github/workflows/build.yml` уже есть в репозитории и НЕ должен удаляться.
2. Открыть вкладку Actions; дождаться зелёной галочки Build Android APK.
3. Открыть успешную сборку; скачать из Artifacts архив `BLEDOB-Widget-APK`, распаковать `app-debug.apk` и установить на телефон.
4. Открыть BLEDOB Lights, разрешить Bluetooth. Если устройство ещё не выбрано — «Найти BLEDOB», выбрать свой контроллер.
5. Закрыть Lotus Lantern полностью (он может удерживать соединение BLE).
6. Проверить: ВКЛ/ВЫКЛ → красный цвет → синий цвет → яркость 30 % / 100 %. Сообщить, какой пункт сработал.
7. Удалить старый ярлык с рабочего стола; добавить новый в разделе «Устройство и настройки».

**Важно о подписывании:** отладочный APK, собранный отдельным запуском GitHub Actions, может иметь другую подпись. Тогда Android не позволит обновить его поверх предыдущего APK — потребуется предварительно удалить старое приложение (после удаления адрес контроллера выбирается заново). В дальнейшем для бесшовных обновлений нужен постоянный ключ подписи.

## Как это работает

На экране приложения поддерживается одно активное соединение GATT. Команды отправляются по очереди; при быстром движении пальца промежуточные значения цвета и яркости заменяются последними (не блокируя интерфейс). При закрытии экрана соединение освобождается. Ярлык и виджет по-прежнему работают через фоновый сервис v1.4 (не запускают главный экран при нормально настроенном устройстве).

Команды RGB и яркости известны для семейства ELK-BLEDOB/ELK-BLEDOM. Power оставлен из проверенной старой версии:

```text
Lotus Lantern: 7E 04 04 01 00 01 FF 00 EF (ON)
RGB:           7E 07 05 03 RR GG BB 10 EF
Brightness 0:  7E 04 01 PP FF FF FF 00 EF
Brightness 1:  7E 04 01 PP 01 FF 02 01 EF
```

Состояние отображается по последней **успешно отправленной команде**, а не по ответу самого контроллера: устройство может не передавать текущие цвет/яркость обратно. Если включать свет другим приложением или пультом, значения на экране могут расходиться с фактическими до следующей команды.

## Android / build

- minSdk: 26 (Android 8.0), targetSdk: 35
- Java 17, Gradle 8.9 / Android Gradle Plugin в `build.gradle`
- `applicationId` сохранён: `com.example.bledobwidget`
- Для GitHub Actions: `.github/workflows/build.yml`
- Проект не использует сеть, аналитику, рекламу, аккаунты или внешние зависимости UI.
