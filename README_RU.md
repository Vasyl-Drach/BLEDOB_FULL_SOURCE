# Bingo LED 2.1 — Android-приложение для BLEDOB

Полностью бесплатная офлайн-замена Lotus Lantern для контроллера **BLEDOB**.

## Что изменилось относительно рабочей версии 2.0

- Название приложения и заголовок главного экрана: **Bingo LED**.
- Плавное включение за **1,5 секунды**: сначала команда ON, затем яркость постепенно увеличивается от 1% до сохранённого значения.
- Плавное выключение за **1,5 секунды**: яркость плавно уменьшается до 1%, затем отправляется команда OFF.
- Плавность действует при нажатии в приложении, через виджет и через компактный ярлык «Свет» 1×1.
- Цвет, установленная яркость, выбранный контроллер и вариант BLE-протокола сохраняются.
- Фоновое управление работает без открытия главного экрана. Команды BLE сериализованы — следующая отправляется после подтверждения предыдущей.
- В приложении предусмотрено повторное нажатие во время перехода для изменения направления.

**Время 1,5 секунды относится к самому затуханию/разгоранию.** Для ярлыка и виджета дополнительно требуется время на BLE-подключение (оно зависит от телефона и контроллера). Если контроллер очень медленно подтверждает записи, переход может занять немного больше времени.

При включении контроллер сначала получает команду ON. Некоторые аппаратные ревизии могут на мгновение зажечь свет на старой яркости до первой команды 1%; мы не можем гарантировать отсутствие краткого всплеска без испытания с реальным BLEDOB.

## Как собрать APK через GitHub

1. Распакуй ZIP `Bingo_LED_2_1_UPLOAD_GITHUB.zip`.
2. Загрузи всё содержимое (папку `app`, файлы `build.gradle`, `settings.gradle`, `gradle.properties`, `gradle/wrapper/...` и README) в **корень** того GitHub-репозитория, где уже работает `build.yml`.
3. Нажми **Commit changes**.
4. Вкладка **Actions**: дождись зелёной галочки задания **Build Android APK**.
5. В успешной сборке скачай из **Artifacts** архив `Bingo-LED-APK` (если старый `build.yml` остался без изменений, имя архива будет прежнее `BLEDOB-Widget-APK`). Внутри будет `app-debug.apk`.
6. Установи APK на телефон. Если Android откажет из-за другой подписи debug APK, придётся удалить прежнюю версию, после чего заново выбрать контроллер.

**Важно:** файл `.github/workflows/build.yml` уже находится в существующем репозитории. Для обновления не нужно его менять. Полная резервная копия со сценарием GitHub Actions — `Bingo_LED_2_1_FULL_SOURCE.zip`.

Сохрани предыдущий рабочий APK 2.0, пока не проверишь новый переход на своей ленте.

## Возможности

- Цветовой круг, готовые RGB-цвета, ползунок яркости 1–100%.
- Питание из приложения, виджета и ярлыка на рабочем столе.
- Использует прямое соединение Bluetooth LE, не нуждается в интернете, аккаунте или подписке.
- Идентификатор пакета **не изменён** (`com.example.bledobwidget`) ради сохранения настроек при обновлении.
- Протокол BLEDOB у разных ревизий может немного отличаться; сохраняется ручной выбор варианта.

## Техническая информация

- Android 8+ (minSdk 26), targetSdk 35, Java 17, Gradle 8.9.
- Общий класс `FadeMath.java`: линейная интерполяция яркости по времени, 1500 мс и интервал BLE-записи около 115 мс.
- `BleCommandService.java`: самостоятельный BLE-переход в сервисе для ярлыка/виджета.
- `LiveBleController.java`: переход в рамках текущего GATT-соединения на главном экране.
- Сохраняется конечное значение яркости, а не промежуточные проценты перехода.
- Приложение не получает реальную телеметрию состояния от BLEDOB: иконка показывает последнее успешно отправленное состояние.

**Проверено в этой среде:** структура XML/ZIP, синтаксический анализ Java и автономные тесты линейного расчёта яркости. **Не проверено:** сборка через Android SDK и фактическая плавность на BLEDOB (нет устройства). Первую установку рассматривай как тестовую.
